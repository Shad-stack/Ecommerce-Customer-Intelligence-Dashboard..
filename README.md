# Ecommerce-Customer-Intelligence-Dashboard

## Project Overview

This project analyzes e-commerce sales, customer behavior,
product performance and profitability using SQL, Python and Power BI.

## Tools & Technologies

- SQL / MySQL
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Power BI
- DAX

## Business Objectives

- Analyze sales and profit trends
- Identify high-value customers
- Analyze customer retention
- Identify profitable and loss-making products
- Evaluate discount impact
- Analyze regional and channel performance
- Segment customers using RFM analysis

## Project Workflow

Data → SQL → Python EDA → Power BI → Business Insights.
